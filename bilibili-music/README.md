# Bilibili Music

面向 Owlbear Rodeo 房间的无服务器 Bilibili 音乐播放器。

## 功能

- GM 添加完整 Bilibili 视频链接或 BV 号，管理最多 25 首房间歌单。
- GM 播放、暂停、继续、停止、切歌、排序和移除音乐。
- 所有用户通过后台隐藏的 Bilibili 官方播放器播放同一首音乐，并按房间时间点续播，不展示视频画面。
- 当前音乐结束后默认自动重播。
- 每位用户单独调整音量、拖动或隐藏紧凑的音乐控制条；隐藏控制条不会停止音乐。
- GM 可把歌曲收藏在当前 Chrome 浏览器，之后重新加入任意房间歌单。

## 限制

- 插件不下载或转存音频，视频可用性、广告、地区和登录限制均由 Bilibili 决定。
- Bilibili 普通视频播放器没有公开完整的跨域控制接口；音量滑条使用兼容控制，其中静音会通过重新载入静音播放器保证生效。
- Chrome 可能阻止首次有声自动播放。若没有声音，请点击控制条右上角的 `🔊` 重新启用声音。
- 纯静态网页无法可靠展开 `b23.tv` 短链；请使用包含 `BV...` 的完整视频链接或直接输入 BV 号。
- 新加入的歌曲会读取时长用于自动循环；读取失败时仍会向官方播放器请求循环播放。
