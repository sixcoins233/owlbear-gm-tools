# Destiny & Dice

一个纯静态、无独立服务器的 Owlbear Rodeo 多骰池插件。

## 功能

- 玩家可自由组合 d4、d6、d8、d10、d12、d20、d100，单次最多 100 枚。
- GM 可为每种骰子设置秘密的最小值和最大值；范围仅保存在 GM 当前浏览器的 `localStorage`，不会写入房间元数据或发送给玩家。
- 玩家发送骰池请求后，由在线 GM 客户端使用 `crypto.getRandomValues` 在秘密范围内生成每枚骰子的点数。
- 结果由 GM 广播，所有在线成员都会看到同步的 2D 多面骰滚入、旋转和总计动画。
- 提供深紫漩涡、绿宝石、星霜和秘法炎阳四种动态预设。

## 使用条件与限制

GM 必须在线并启用插件，玩家才能投掷。范围设置按 GM 的浏览器保存；GM 换设备或清除站点数据后需要重新设置。

无服务器插件无法抵御主动修改客户端代码的恶意用户。本插件会检查结果广播者是否为房间中的 GM，可防止普通界面操作伪造结果，但不等同于受信任服务器上的密码学防作弊。
