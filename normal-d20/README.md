# Normal Dice

对 1–20 的每个整数按 `exp(-0.5 × ((点数 - 中心值) / σ)²)` 计算权重，再归一化后抽取，因此结果永远是合法的 d20 点数。

## 功能

- GM 始终可以投掷，并能按在线玩家逐个授权。
- GM 可切换“所有人公开”或“仅 GM 可见”；隐藏结果可由 GM 稍后公开。
- 每个有权限的用户可独立调整中心值、宽度 σ 与额外加值。
- 骰子飞入动画、暴击粒子、实时概率柱状图、最近 10 条公开结果。
- 权限和公开历史保存在 Owlbear 房间元数据；个人滑条位置保存在本机浏览器。

## 无服务器限制

这是协作型跑团工具，不是防作弊系统。隐藏消息仍通过 Owlbear 客户端传输，界面只向 GM 和投掷者呈现；懂开发工具并主动篡改插件的玩家理论上能绕过界面限制。需要强防作弊时必须使用受信任服务器生成随机数并控制数据访问。
